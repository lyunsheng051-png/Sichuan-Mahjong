# 上桌：四川麻将训练设计

## 训练目标

面向懂基本规则、实物牌桌容易漏碰杠或认不出听牌的初学者。把“能不能玩好”拆成可练习、可核对的动作，不把表现差归因于记忆能力或医学问题，也不承诺固定天数精通或改变特定脑网络。

关键区别：记住整副牌与及时识别可操作牌不同；挑出孤张与识别全手听牌结构也不同。因此先专项训练，再迁移到实物，不以完整自动提示对局作为起点。

## 当前实现

1. **手牌快照**：观察13张牌4 / 8 / 12秒后收起，回忆所有对子与刻子的牌种；允许提交“没有”。重看、提示均计为辅助。
2. **碰杠反应**：均衡抽样可碰、可直杠、数量不足、定缺禁碰。手里三张时碰和直杠都属于合法答案。先开牌练识别，再收牌练注意力切换。只评估碰与直杠，不评估胡、暗杠、补杠或操作收益。
3. **听牌侦探**：13张手牌选全听口，约25%出题尝试为未听牌；逐个听口展示一种合法完整拆法。包含复合牌型和可关闭的七对。
4. **打哪张能听**：14张牌找出所有一打即听的弃牌，逐项显示听口与一种补牌后的拆解，不排名番数、防守或实际余牌。
5. **换三张练习**：13张开局选同花色三张，只判合法性；模拟收到同花色三张，观察交换后的结构。未模拟四家交换方向与定缺决策评分，不宣称最优换牌。
6. **手牌实验室**：手动录入13 / 14张未碰杠暗手牌，检查胡牌、听口、可听弃牌。禁止录入第五张同牌。
7. **练习记录**：当前浏览器保存最近300次，记录用时、独立 / 辅助、准确性、原题、当时规则；支持筛选与原题重做，默认每页10条，可选20 / 50条。

每题提交前不展示答案；提交后展示答案、原因、合法拆分。计时从进入答题阶段开始，排除记牌阶段。无速度奖励，避免鼓励猜题。换牌合法率不计入总独立识别准确率。

## 规则边界

- 万、条、筒各1～9，每种4张，共108张。
- 换同一花色三张后定缺。模拟交换不构成完整四人对局。
- 定缺花色不能碰、杠、胡；含缺门牌时优先打缺门牌。
- 普通胡为四组面子加一对将，顺子不能跨花色。
- 可选七对，无碰杠，四张同牌允许作两对。
- 求解器支持传入已碰杠组与相应暗手牌张数；当前界面只生成无副露题目，实验室也只接收无副露手牌。
- 结构听口排除自己已经持有四张的牌，不凭空估算牌墙剩余数量。
- 当前不判断番型分值、封顶、过水、杠上炮、查叫、查花猪和完整血战流程。

## 学习路线

以15～20分钟为一次练习参考，疲劳时停止。以下门槛是训练设计目标，不是经过临床或教学实验验证的效果承诺。

| 阶段 | 重点 | 进阶参考 |
| --- | --- | --- |
| 起步（第1～3次） | 12秒手牌快照、开牌碰杠 | 最近20道手牌题独立准确率至少90% |
| 注意力转移（第4～7次） | 收牌碰杠，12秒逐步降为8秒 | 至少20道收牌碰杠题，独立准确率至少90% |
| 听牌结构（第8～14次） | 听牌侦探、打哪张能听 | 连续两次各20题独立准确率至少90%，能口述拆解 |
| 实物迁移 | 实物摆牌、先写听口，再用实验室核对 | 慢速亲友局中记录漏碰杠与漏听原因，回到相应专项 |

不锁关，不用首次答题时间判定掌握。重复原题答对可能来自记答案，需混入新题检验。

## 继续进阶的范围

未来完整陪练应增加：无提示连续摸打、主动报告每次听口变化、真实牌河与可见余牌、碰杠后重组、防守与番型收益、完整血战结算。上述功能未在本版本实现，不能把专项准确率等同于实战精通。
