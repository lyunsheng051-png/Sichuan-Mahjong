# 上桌 · 川麻练习室

面向懂规则但容易漏碰杠、认不出听牌的初学者。Vue 3 + Vite + TypeScript 本地训练程序，无需账号、后端或数据库。包含换三张练习，重点训练主动判断。

## 启动

```powershell
npm install
npm run dev
```

打开终端输出的本地地址。检查类型：

```powershell
npm run typecheck
```

按项目约定，不要求运行 build。

## 已实现

- 手牌快照：观察后收牌，回忆对子与刻子。
- 碰杠反应：开牌 / 收牌，识别可碰、可直杠或都不能。
- 听牌侦探：选全听口，包含未听牌题；作答后看完整拆解。
- 打哪张能听：选出所有一打即听弃牌，比较听口。
- 换三张：同花色三张合法性检查，模拟换入后重整手牌。
- 手牌实验室：录入未碰杠的13 / 14张牌，自主核对。
- 本地记录、错题重做、独立 / 辅助区分、分页（默认10条，可选20 / 50）。

## 练习规则与限制

108张万条筒、定缺、不能吃、可碰杠；普通胡四组加一对，七对可开关，四张相同牌可作两对。当前只训练结构识别与换牌合法性，不包含完整四人对局、番数结算、防守和实际剩余张数计算。不能把准确率或练习次数视为实战精通。

训练数据仅保存在当前浏览器的 localStorage，最多300次记录。清除浏览器数据会丢失进度。页面不调用外部服务；牌面随项目本地提供。

完整学习路线与设计理由见 [训练设计](docs/training-design.md)，牌面来源与许可见 [第三方说明](THIRD_PARTY_NOTICES.md)。

```text
src/composables/      训练状态与练习进度
src/config/           训练模式、默认设置
src/layouts/          应用布局
src/router/           页面路由
src/services/         胡牌/听牌求解与出题逻辑
src/styles/           主题变量与响应式样式
src/types/            牌、题目、记录类型
src/views/            首页、训练、记录、手册、实验室
```
